TeX Live 2026 package files (core/busytex/texlive-basic.*)
---------------------------------------------------------
LaTeX classes, packages and fonts from TeX Live 2026, served unmodified.
Each package has its own license (mostly the LaTeX Project Public License,
also GPL, OFL, public domain and others). TeX Live's own license notes
(LICENSE.TL, LICENSE.CTAN) are inside the bundle.
  Source:  https://tug.org/texlive/   https://ctan.org/
TeX package files that are not in this bundle are fetched one at a time
from TeXlyre's public package server, https://texlive2026.texlyre.org.
